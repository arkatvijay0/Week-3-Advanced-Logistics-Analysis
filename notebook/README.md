# Jupyter Notebook

This folder contains the Jupyter Notebook used to perform the complete Week 3 logistics data analysis.

## Notebook

`Week_3_Logistics_Analysis.ipynb`

## Analysis Performed

The notebook contains the following workflow:

1. Load the processed logistics dataset.
2. Inspect the dataset structure.
3. Check data types, missing values, and duplicates.
4. Perform descriptive statistical analysis.
5. Calculate mean, median, standard deviation, minimum, and maximum values.
6. Analyze numerical variable distributions.
7. Perform correlation analysis.
8. Identify the strongest numerical relationship.
9. Analyze daily shipment volume.
10. Perform outlier analysis.
11. Generate the final visualizations.
12. Save analysis outputs.
