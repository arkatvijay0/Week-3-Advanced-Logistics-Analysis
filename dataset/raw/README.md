# Dataset

This folder contains the datasets used for the Week 3 Advanced Data Analysis and Visualization in Logistics project.

## Files

### Raw Dataset

`dynamic_supply_chain_logistics_dataset(1).csv`

The original logistics dataset used as the starting point for the project.

## Data Cleaning

The processed dataset was prepared by:

* Standardizing column names.
* Converting timestamp data into datetime format.
* Checking for missing values.
* Checking for duplicate records.
* Preserving valid observations and potential outliers.

## Dataset Size

* **Records:** 32,065
* **Variables:** 26

The processed dataset is the primary dataset used in the Jupyter Notebook and analysis.
